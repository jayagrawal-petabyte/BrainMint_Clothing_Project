# Meeting Notes

This folder contains all meeting records related to the Business Analyst project.

## Purpose
To document discussions, requirements clarification, and decisions made during meetings with stakeholders and team members.

## Contents
- Meeting 01: Initial Project Discussion
- Meeting 02: Requirements Gathering
- Meeting 03: Requirement Clarification (if any)

## Format Used
Each meeting file contains:
- Date of meeting
- Attendees
- Discussion points
- Decisions made
- Action items
